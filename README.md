# Who Pays When the Government Taxes Colleges?

This repository contains datasets and code for the paper titled "Who Pays When the Government Taxes Colleges?" 

# Data Availability

This paper uses data from two sources:

1. IPEDS: Available at NCES https://nces.ed.gov/ipeds/
2. Form 990:
   - Data from 2019 and beyond are available at: https://www.irs.gov/charities-non-profits/form-990-series-downloads
   - Earlier data are previously available via Amazon Simple Storage Service (Amazon S3): https://aws.amazon.com/blogs/publicsector/irs-990-filing-data-now-available-as-an-aws-public-data-set/, but the IRS no longer maintains the dataset since 2021.
   - Users could still obtain earlier Form 990 data from third-party sources, such as: Propublica Nonprofit Explorer https://projects.propublica.org/nonprofits/

This repository contains the main dataset for producing tables and figures. Due to the large amounts of raw data and intermediate data, they are not uploaded to this repository. The intermediate data are available from the corresponding author upon reasonable request.

# Code Availability

The codes (Stata do files) of data construction and analysis are available at this repository.
